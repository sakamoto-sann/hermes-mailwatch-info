Omarchy Hermes Mailwatch

A privately operated tool for monitoring the operator’s own Google accounts.

With each account holder’s consent, it checks Gmail message headers, recently changed Drive file metadata, and upcoming Calendar event titles and times. A local language model creates a digest, delivered to the operator’s private Telegram chat.

The current collector does not download email bodies, attachments, or Drive file contents. It does not send email, mark messages as read, delete files, or change calendar events.

Requested Google permissions are gmail.readonly, drive.readonly and calendar.readonly. These permissions are broader than the metadata currently collected: they technically allow reading additional content through the respective APIs. The collector uses only the metadata described above.

This is a personal-use application, not a public account-connection service. Each Google account requires its holder’s explicit authorization.

Read the Privacy Policy and Terms of Use. Questions: project issue tracker. Do not post account information, messages, tokens or other private data there.
